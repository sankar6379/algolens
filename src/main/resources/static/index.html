RECOMMENDED APPROACH

Hash Map — one pass

O(n) time
WHY IT WORKS

At each number, ask: “Have I already seen its complement?” A hash map answers in constant time, removing the second loop entirely.

Map<Integer, Integer> seen = new HashMap<>();
for (int i = 0; i < nums.length; i++) {
    int need = target - nums[i];
    if (seen.containsKey(need))
        return new int[] {seen.get(need), i};
    seen.put(nums[i], i);
}
TRADE-OFF

Uses O(n) extra memory to reduce runtime from quadratic to linear.
